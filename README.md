# Extraction Mode - Traduction française

French translation of [Extraction Mode](https://steamcommunity.com/sharedfiles/filedetails/?id=3785397275) by Zakreon, for Project Zomboid Build 42.21.

- Mod id: `batman_ExtractionModeFR` (requires `ExtractionMode`)
- Translated files: `Contents/mods/batman_ExtractionModeFR/42.21/media/lua/shared/Translate/FR/*.json`
- Based on Extraction Mode 0.9.6 (1,495 keys: interface, quests, messages, items, sandbox options)

## Install

Subscribe on the Steam Workshop, enable Extraction Mode and this mod, and set the game language to Français.

## Updating the translation

When Extraction Mode adds or changes texts, compare its `Translate/EN` files with the `FR` files here: same keys, and every value keeps the same `%1`, `%%`, `<LINE>`, `<SIZE:...>` tokens and line breaks as the English text.

`source/make_poster.py` rebuilds the poster from the original Extraction Mode artwork (Pillow).
